<task type="auto">
  <name>Task 2: Create docker-compose.yml with service configuration</name>
  <files>docker-compose.yml</files>
  <action>
  Create docker-compose.yml (version 3.8+) with:
  - **Single service named `frontend`**: Runs the Next.js app on port 3000 (accessible via localhost:3000)
  - **Build context**: Use build: {context: ., dockerfile: Dockerfile}
  - **Environment variables**: Pass NODE_ENV=development, expose port 3000
  - **Volumes for dev**: Mount src/ directory for hot-reload (bind mount: ./src:/app/src)
  - **Command override**: For development, use `npm run dev` instead of default next start (allows code changes to auto-refresh)
  - **Networks**: Default network is fine, but optionally name it for clarity
  - **Resource limits**: Optional but recommended (cpu: 1, memory: 512M) to prevent runaway containers

  Structure:
  ```yaml
  version: '3.8'
  services:
    frontend:
      build:
        context: .
        dockerfile: Dockerfile
      ports:
        - "3000:3000"
      environment:
        NODE_ENV: development
      volumes:
        - ./src:/app/src
        - node_modules:/app/node_modules
      command: npm run dev
  volumes:
    node_modules:
  ```

  Why this approach:
  - Single service running all pages (not per-page services) keeps it simple for local dev
  - Hot-reload via volume mount allows instant feedback on code changes
  - Per-page services would complicate port management and dev workflow
  - Production will bundle everything into single image anyway

  Avoid:
  - Named volumes for src/ (use bind mount for live editing)
  - Multiple services per page (overkill for local dev)
  - Exposing internal ports in production (will be handled differently in Phase 4)
  </action>
  <verify>docker-compose ps shows frontend service, docker-compose logs frontend shows "ready - started server on localhost:3000", curl localhost:3000 returns 200</verify>
  <done>docker-compose up starts the app successfully, pages are accessible on localhost:3000, code changes hot-reload</done>
</task>
