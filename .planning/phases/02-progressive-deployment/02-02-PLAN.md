<task type="auto">
  <name>Task 1: Create GitHub Actions workflow for Docker build and registry push</name>
  <files>.github/workflows/preview.yml</files>
  <action>
  Create .github/workflows/preview.yml workflow that:
  - **Trigger**: On push to all branches and PRs (branches: '*', pull_request: true)
  - **Build environment**: Use ubuntu-latest
  - **Steps**:
    1. Checkout code (actions/checkout@v4)
    2. Setup Docker Buildx (docker/setup-buildx-action@v3) - enables advanced features like caching
    3. Build Docker image with tags:
       - Tag 1: registry.example.com/pbe-frontend:${{ github.sha }} (commit hash - unique per commit)
       - Tag 2: registry.example.com/pbe-frontend:${{ github.ref_slug }} (branch name - for branch previews)
       - Tag 3: registry.example.com/pbe-frontend:latest (for main branch only)
    4. Push to registry (docker/build-push-action@v5)
    5. Output image URL for next job

  Docker registry options (choose one for user decision later):
  - GitHub Container Registry (ghcr.io): Free with GitHub, no additional setup
  - Docker Hub: Popular, straightforward, free tier limited
  - AWS ECR: More enterprise, paid but cheap for small usage
  - Custom registry: More control, requires hosting

  For now, use placeholder "registry.example.com" and document the options.

  Environment variables needed (GitHub Secrets):
  - REGISTRY_USERNAME: Docker registry username
  - REGISTRY_PASSWORD: Docker registry password/token

  Cache strategy:
  - Use docker/build-push-action built-in cache (type=gha)
  - Cache Next.js build cache between builds (mount type=cache)
  - Reduces build time from ~3-5min to ~1-2min on cache hit
  </action>
  <verify>GitHub Actions workflow runs on push, builds Docker image, no errors in logs</verify>
  <done>Workflow creates Docker image per commit, pushes to registry with unique tags, build cache working</done>
</task>

<task type="checkpoint:decision" gate="blocking">
  <decision>Select Docker registry for storing built images</decision>
  <context>
    The CI/CD pipeline needs to push built Docker images somewhere. Each registry has different tradeoffs:
    - **Storage**: Where images are stored
    - **Access**: Who can pull images
    - **Cost**: Pricing model
    - **Setup**: Configuration complexity
  </context>
  <options>
    <option id="ghcr">
      <name>GitHub Container Registry (ghcr.io)</name>
      <pros>Free tier with GitHub, no additional signup, automatic GitHub auth, good for open-source and private repos alike, tight GitHub integration</pros>
      <cons>Slightly less mature than Docker Hub, limited free tier storage (~5GB shared across all), slower first pull</cons>
    </option>
    <option id="dockerhub">
      <name>Docker Hub</name>
      <pros>Most popular, fast image pulls, generous free tier, mature platform</pros>
      <cons>Free tier limited to 1 private repo, rate limiting for pulls (100/6hrs for anonymous, 200/6hrs authenticated), can get expensive</cons>
    </option>
    <option id="ecr">
      <name>AWS ECR</name>
      <pros>Integrated with AWS ecosystem, pay-per-image pricing (~$0.07/GB stored), very fast pulls on AWS infrastructure</pros>
      <cons>Requires AWS account, more setup complexity, manual cleanup needed to avoid costs</cons>
    </option>
    <option id="custom">
      <name>Self-hosted Registry</name>
      <pros>Complete control, no vendor lock-in, can run on existing infrastructure</pros>
      <cons>You manage security, backups, storage, uptime - significant operational overhead for small project</cons>
    </option>
  </options>
  <resume-signal>Select: ghcr, dockerhub, ecr, or custom. (GHCR recommended for Phase 2 - simplest setup)</resume-signal>
</task>

  <action>
  Update workflow to generate and document preview URLs:

  **In preview.yml, add outputs:**
  ```yaml
  outputs:
    preview-url: ${{ steps.generate-url.outputs.preview-url }}
    image-tag: ${{ steps.generate-url.outputs.image-tag }}
  ```

  **Add step to generate URL:**
  ```yaml
  - name: Generate Preview URL
    id: generate-url
    run: |
      BRANCH=$(echo ${{ github.ref_slug }} | tr '/' '-')
      PREVIEW_URL="https://preview-${BRANCH}-${{ github.run_id }}.staging.parebriseexpress.ma"
      IMAGE_TAG="${{ github.sha }}"
      echo "preview-url=${PREVIEW_URL}" >> $GITHUB_OUTPUT
      echo "image-tag=${IMAGE_TAG}" >> $GITHUB_OUTPUT
  ```

  **Add job to post comment on commits/PRs:**
  - If event is push: Post commit comment with preview URL
  - If event is pull_request: Post PR comment with preview URL
  - Use GitHub API: `gh pr comment` or Actions comment action

  ```
  🚀 Preview deployed!

  Review checklist:
  - [ ] Homepage loads without errors
  - [ ] Navigation works on mobile (375px)
  - [ ] All images load correctly
  - [ ] Responsive layout on tablet (768px)
  ```

  **Documentation:**

  - Document how to access staging (e.g., "Preview URLs are live for 7 days")
